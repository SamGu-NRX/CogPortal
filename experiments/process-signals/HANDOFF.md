## Current-invocation gating for the TS arm (this correction)

The ablation comparison used to gate on file existence: if a current `tsx` invocation failed,
stale `{id}.ts.{base,ablated}.json` files from an earlier (already-committed) run were still on
disk, the existence gate passed, and the failed run was compared as if it had executed. Fixed in
`run.py`: every TS comparison now reads only outputs the worker produced during this run.py
invocation, with a matching run identity —

- the runner stamps each live invocation with a `runId` (recorded in `confusion-table.json` and
  in every unexercised record) and hands the worker an invocation-scoped staging path;
- the adapter (`run-worker.ts`) accepts `--run-id <id>`, echoes `run-id <id>` on stderr, and
  never writes it into the canonical output bytes;
- the runner publishes the staged output (atomic replace) only when the worker exited zero AND
  the stderr carried exactly this run's id; otherwise the arm stays unexercised and any
  pre-existing published file is left untouched and unread.

Regression: `tests/test_run_identity_gate.py` — a failing current run with stale ablation files
seeded whose diff would read as `confirmed` stays `unexercised-ts` (`tsDeltaPaths` null), stale
bytes are byte-identical after the run, a run-id mismatch is never published, a matching run-id
publishes and consumes the staging file.

Receipts regenerated by a fresh live run (`pnpm exec tsx` exercised, `runId
6c9b4b9b38f24ad683ad20319f6ed228`): 17 rows, 0 unexpected verdicts — every verdict row is
byte-identical to the previous receipts. Only the identity fields moved: `confusion-table.json`
gained `runId` and its `tsxInvocation.cwd` now names this run's checkout; `summary.md` changes
by that one cwd line (hash pair now `4bfaa92f…`, equal on both sides of `regeneration.json`);
all per-run bytes unchanged. Suite: `python3 -m pytest -q experiments/process-signals/tests` →
**38 passed** (35 + 3 new).

## Standing limits

See `unsupported-interpretations.md` — in particular: an unexercised arm supports no claim; a
zero-delta ablation cannot rule out reading in unreached code paths; absence findings inside a
truncated window are not attributable. No per-person totals or grades exist anywhere in this study.
