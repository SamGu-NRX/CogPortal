# Verification: the sandbox and the cross-cutting concerns

How to run this file: the sandbox has no interface of its own, so every item here is observed through the run page, the failure card, or the live console. Start hosted runs from the dev portal against repositories you have prepared to produce each outcome. Several items need a repository built to fail in a specific way; the Setup column names what that repository has to do, and preparing them is most of the work in this file.

Rows are read against `2ff32fa`. The only hosted execution evidence is two Recognition practice runs on hosted beta (`4984730` lineage): `run_f5fc5babe5` failed in Evaluate before beta's `468655c`, and its Retry `run_f93ba19397` succeeded at 0.925. A row they exercised says `on beta only`; no hosted run of Audio, Clustering or Language exists for either build.

This file also holds the cross-cutting and foundations tables, one per document, because their claims are observed through the same run pages.

Budget runs before starting. A hosted run takes minutes and the practice quota is ten per team per benchmark version, so a full pass needs several teams or a raised limit. Plan which repository produces which outcome first.
