# Why this directory exists

Three files, each answering a question that kept getting re-litigated because
the answer lived in a chat log nobody could search.

- `ideation-guideline.md` — the owner's direction for what CogPortal is for,
  recorded verbatim. Every design decision in this repository answers to it.
  Read this first.
- `what-the-course-actually-taught.md` — what the instructors told students, in
  their own words, with timestamps. Used to settle arguments about what the
  benchmark should reward. The short version: the course graded process, and
  said so out loud.
- `transcript-evidence.txt` — the raw claim/evidence/why records that
  `what-the-course-actually-taught.md` was written from, across 19 days of
  class recordings. Kept because the summary drops the surrounding context and
  someone will eventually want it back. Grep it by claim category
  (`PURPOSE:`, `WORK SPLITTING:`, `ASSESSMENT:`).
